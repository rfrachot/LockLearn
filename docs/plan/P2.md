## P2.2 — Profiles, presets and HA-user mapping

**Status:** PASS.

**Spec:** §18, §19, §89

### Deliverables
- [x] Create profiles independent of HA users/devices.
- [x] Support personal profile onboarding and child/standard/intensive/custom presets.
- [x] Allow child/shared profiles without dedicated HA accounts.

### Exit criteria
- [x] Creating a personal profile does not make Profile == HA User.
- [x] Preset values are defaults, not irreversible restrictions.

Implementation note: Home Assistant ConfigFlow context does not identify the authenticated
HA user. The config-flow checkbox remains a setup preference; idempotent personal-profile
creation is exposed by the profile service and is intended to be invoked from the first
authenticated LockLearn bootstrap surface in P2.6. This preserves `Profile != HA User`
without guessing an owner during config-entry setup.
