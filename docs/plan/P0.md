## P0.3 — SQLite concurrency, state/content boundary and backup spike

**Spec:** §67, §68, §69, §70, §71, §72, §73, §80, §128

### Deliverables

- [x] Prototype dedicated state writer + separate/thread-local readers; prove no sqlite I/O on HA event loop.
- [x] Validate WAL, busy_timeout, foreign_keys and active content.db attach model.
- [x] Benchmark content merge/generation and hot due/new queries on representative fixture sizes.
- [x] Validate coherent backup using checkpoint + Connection.backup(); test content-cache location/exclusion options.

### Exit criteria

- [x] No sqlite connection is shared naïvely across threads.
- [x] User interactions remain responsive while long operations run.
- [x] Backup strategy is proven on supported HA lifecycle.
- [x] Content/state remain physically and logically separated.
