## P5.1 — Frontend shell, protocol/bootstrap and routing

**Spec:** §45, §46, §47, §65, §91

### Deliverables
- [x] Build Lit/Vite panel shell using HA WebSocket only.
- [x] Implement bootstrap state, routing, protocol/version mismatch handling and cache-busted bundled artifact.
- [x] Avoid runtime CDN dependencies and direct SQLite access.

### Exit criteria
