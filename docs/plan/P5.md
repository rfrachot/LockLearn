### Exit criteria

**Automated qualification (2026-09-26):** P5.3 uses backend-owned CardDefinition presentation, persists introduction and post-retrieval signals atomically with session CAS, and schedules the mandatory first retrieval after introduction in the same session. The follow-up question is appended atomically, carries its backend `available_at_utc`, is rejected server-side before its learning-step due instant, and renders only a waiting surface until due; prompt, answer and hints remain hidden during that interval. Direction mapping, hint persistence, stale-CAS single-winner behavior and content reporting are covered by backend tests.

An initial 390×844 qualification exposed a real horizontal overflow on the essential “Continuer” action; the responsive containment fix was deployed and the same 390×844 viewport then passed with no blocking horizontal overflow.

The active pack exposed no card with `hint_blocks` or `mnemonic_blocks` in the 100 cards inspected, so a real-instance hint smoke test was not possible. This is a content-fixture limitation rather than a runtime failure: automated backend/frontend coverage verifies hint visibility and persistence of `hint_used=true`. P5.3 therefore closes PASS with that evidence split documented explicitly.

## P5.4 — Quiz/free-text/cloze UI

**Status:** IMPLEMENTED / REAL-HA QUALIFICATION PENDING.

**Spec:** §51, §52, §79

### Deliverables
- [x] Render MCQ, free_text and cloze-MCQ with corrective feedback and context hints.
- [x] Support unrecognized recovery/report action and contrastive confusion feedback.
- [x] Do not rely on color-only status.

### Exit criteria
- [ ] All V1 quiz formats work on desktop/mobile and keyboard.

**Automated qualification (2026-09-26):** the Quiz route is wired to backend-owned session preparation and atomic quiz answer submission. MCQ/cloze payloads never expose the correct marker, panel MCQ uses 4 options by default, explicit IDK is supported, and corrective feedback is returned only after submission. Free-text grading is provisional before commit, does not reveal the correct answer on a wrong provisional grade, and supports “should be accepted” recovery as `unrecognized` without an automatic SRS failure. Cloze-MCQ is restricted to grammar content with explicit maskable source content; no heuristic answer masking is invented in the frontend. Known-confusable distractors can return contrastive feedback, and feedback uses text labels rather than color-only state.

The authoritative pre-bundle code gate at `3f7047697d8dc56565cf717106d52c6e3823cfab` passed Ruff format/lint (256 files), mypy (148 sources), registries, 389 pytest tests, HA 2025.2.5 and HA 2026.9.3 backend matrices (296 tests each), TypeScript and 11 Vitest files / 31 tests. Vite built 29 modules at 97.71 kB / 20.94 kB gzip. The generated bundle was then materialized and the normal frontend reproducibility gate passed on descendant `948bb03e5a974ec5b68fb99ed076990bc9dcea8a`.

The remaining P5.4 gate is targeted real-instance qualification of MCQ, free_text and cloze-MCQ on desktop/mobile/keyboard, plus the user-visible unrecognized/report and contrastive-feedback paths when suitable content fixtures exist. Do not start P5.5 before that gate is recorded.
