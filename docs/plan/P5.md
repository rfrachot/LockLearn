## P5.4 — Quiz/free-text/cloze UI

**Status:** PASS.

**Spec:** §51, §52, §79

### Deliverables
- [x] Render MCQ, free_text and cloze-MCQ with corrective feedback and context hints.
- [x] Support unrecognized recovery/report action and contrastive confusion feedback.
- [x] Do not rely on color-only status.

### Exit criteria
- [x] All V1 quiz formats work on desktop/mobile and keyboard.

**Automated qualification (2026-09-26):** the Quiz route is wired to backend-owned session preparation and atomic quiz answer submission. MCQ/cloze payloads never expose the correct marker, panel MCQ uses 4 options by default, explicit IDK is supported, and corrective feedback is returned only after submission. Free-text grading is provisional before commit, does not reveal the correct answer on a wrong provisional grade, and supports “should be accepted” recovery as `unrecognized` without an automatic SRS failure. Cloze-MCQ is restricted to grammar content with explicit maskable source content; no heuristic answer masking is invented in the frontend. Known-confusable distractors can return contrastive feedback, and feedback uses text labels rather than color-only state.

The authoritative pre-bundle code gate at `3f7047697d8dc56565cf717106d52c6e3823cfab` passed Ruff format/lint (256 files), mypy (148 sources), registries, 389 pytest tests, HA 2025.2.5 and HA 2026.9.3 backend matrices (296 tests each), TypeScript and 11 Vitest files / 31 tests. Vite built 29 modules at 97.71 kB / 20.94 kB gzip. The generated bundle was then materialized and the normal frontend reproducibility gate passed on descendant `948bb03e5a974ec5b68fb99ed076990bc9dcea8a`.

**Real-HA qualification — PASS with documented fixture/harness limits (2026-09-26):** a temporary QA Profile/Track was created through LockLearn public APIs and cleaned afterward. On Home Assistant 2026.7.4, MCQ, free_text, the unrecognized/report recovery path, keyboard interaction and clean LockLearn logs all passed. The active pack did not contain grammar content with an explicit maskable block and did not contain a confusable group, so cloze-MCQ and contrastive-feedback smoke tests were fixture-unavailable rather than runtime failures.

The browser harness could not certify the exact 390×844 viewport because Firefox WebDriver enforced a 500 px CSS minimum. No mobile overflow or inaccessible action was observed in the available harness, and the Quiz view uses the same narrow-layout containment rules qualified in automated/frontend tests. P5.4 therefore closes PASS with the exact-390 limitation recorded as a test-harness limitation, not as a product failure.
