## P5.4 — Quiz/free-text/cloze UI

**Status:** PASS.

**Spec:** §51, §52, §79

### Deliverables
- [x] Render MCQ, free_text and cloze-MCQ with corrective feedback and context hints.
- [x] Support unrecognized recovery/report action and contrastive confusion feedback.
- [x] Do not rely on color-only status.

### Exit criteria
- [x] All V1 quiz formats work on desktop/mobile and keyboard.

**Automated qualification (2026-09-26):** the Quiz route is wired to backend-owned session preparation and atomic quiz answer submission. MCQ/cloze payloads never expose the correct marker, panel MCQ uses 4 options by default, explicit IDK is supported, and corrective feedback is returned only after submission. Known-confusable distractors can return contrastive feedback, and feedback uses text labels rather than color-only state.

**Real-HA qualification — PASS with documented fixture/harness limits (2026-09-26):** a temporary QA Profile/Track was created through LockLearn public APIs and cleaned afterward.
