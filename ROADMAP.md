# Roadmap

This file is descriptive. `SPEC_V1.md` and the plan files are authoritative for
committed scope.

## Committed

V1 work through P6 release hardening:

- generic local-first learning/SRS engine;
- Profile/Track ACL model;
- signed dataset/content pipeline and offline starter;
- active learning/quiz/stats panel;
- deterministic scheduler and Companion notifications;
- lifecycle/recovery/security/privacy;
- documentation/contracts, release packaging and final acceptance.

Current next work: P6.9 documentation/contracts, then P6.10 release readiness and
P6.11 V1 acceptance.

## Candidate

Candidates already identified for V1.1/future evaluation include richer media,
advanced free text/cloze, image learning, advanced Japanese presentation and
selected learning UX improvements. A candidate is not a release promise.

See `docs/plan/P7.md`.

## Ideas

Longer-horizon possibilities include cloud/sync-adjacent integrations, broader
content ecosystems and teaching/community workflows. They require explicit spec
promotion before implementation.

## Rejected / out of V1

V1 explicitly does not require:

- LLM tutoring;
- speech/handwriting recognition;
- a native LockLearn mobile application;
- complex gamification;
- optimized FSRS;
- automatic community pack trust;
- cloud accounts/sync.

FSRS/community packs/Anki interoperability/teacher mode remain future candidates,
not hidden V1 requirements.
