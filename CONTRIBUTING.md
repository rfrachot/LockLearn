# Contributing

LockLearn is in an early private bootstrap phase. Contributions are not yet
actively solicited, but the project is structured for future public work.

Before contributing, read `AGENTS.md`, `SPEC_V1.md`, `PROJECT.md`, relevant ADRs
and the active mission. A change is not complete without appropriate tests,
documentation and migration/security consideration.

Contributors retain copyright to their contributions and submit software changes
under the repository's MIT license. Learning/editorial content and third-party
data must have an explicit compatible license; see `LICENSING.md`.
