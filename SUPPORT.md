# Supporting LockLearn

LockLearn is intended to remain usable without a LockLearn cloud account or a
paid backend.

Donations and sponsorship may fund development, hardware/testing devices,
dataset build infrastructure and documentation. They do not override the MIT
software license or third-party data licenses, and do not grant the project the
right to relicense upstream datasets.

Prepared channel:
- GitHub Sponsors: account metadata points to `rfrachot`; the GitHub Sponsors
  profile must be enabled separately in GitHub before the button is functional.

Other channels such as Ko-fi can be added later by updating
`.github/FUNDING.yml` once their public identifier is known.
